# 化学方程式互动实验室

一个面向课堂演示的单页 Web 应用，让化学元素的"相遇"过程直观、可交互、易复用。

## 功能特性

### 元素周期表互动

- 点击任意元素，系统自动高亮可与之发生反应的其他元素
- 不可反应的元素会变暗，引导用户快速找到有效组合
- 支持元素搜索定位，输入符号或名称即可跳转

### 反应方程式生成

- 选择元素组合后，实时展示配平后的化学方程式
- 标注反应类型（化合、分解、置换、复分解等）和反应条件
- 内置 400+ 条化学反应数据，覆盖中学化学常见反应

### AI 智能解释

- 点击反应可唤起 AI 解释弹窗，流式输出详细解读
- 内容涵盖反应原理、工业应用、安全提示、延伸知识
- 帮助学生理解反应背后的逻辑，而非死记方程式
- 上游限流或不可用时自动展示内置反应资料，并提示稍后重试
- 可在弹窗中填写自己的 API Key，仅保存在本机浏览器并直连上游，绕开共享代理限流

### 双模式探索

- **元素高亮模式**：从元素周期表出发，探索元素间的反应关系
- **化合物链式模式**：从化合物出发，追溯其前驱反应物，层层展开

### 反应网络图

- 以可视化图谱展示化合物的前驱反应关系
- 点击化合物节点可展开其前驱反应物和反应条件
- 同一化合物在整张图中只允许展开一次，避免重复和跨层级连线
- 再次点击已展开节点可收拢其前驱结构

### 3D 虚拟实验台

- 首页点击「进入 3D 虚拟实验台」，在沉浸式 3D 实验场景中演示经典化合反应
- 内置 6 个实验：镁条燃烧、铁丝在氧气中燃烧、硫燃烧、红磷燃烧、铜片加热、氢气燃烧
- 按真实操作流程交互：加入试剂 → 点火加热 → 观察现象 → 重置实验
- 3D 特效：酒精灯火焰、反应火焰、烟雾、火星迸射、生成物渐变，并按反应类型呈现对应器材（坩埚 / 集气瓶 / 试管）
- 每个实验附带操作步骤、实验现象与安全提示
- 支持拖拽旋转视角、滚轮缩放；3D 引擎按需加载，不影响首屏速度

### 收藏与本地存储

- 一键保存常用方程式到收藏夹
- 数据存储在浏览器本地，下次打开无需重新查找
- 收藏夹支持快速查看和删除管理

### 响应式设计

- 适配桌面端鼠标操作和移动端触摸操作
- 布局自动适应不同屏幕尺寸

## AI 服务配置与限流说明

前端默认请求 `https://api.chatlz.dpdns.org`，由 `worker/api01-worker.js` 转发到上游模型服务。

Cloudflare Worker 需要配置：

- `API_KEY`（机密）：上游 API Key，必填
- `AI_CACHE`（可选 KV 命名空间）：缓存相同问题的回答，显著降低上游调用量
- `UPSTREAM_API`（可选变量）：自定义上游地址，默认 `https://apihub.agnes-ai.com/v1/chat/completions`

前端可选环境变量：

- `VITE_AGNES_API_URL`：自定义代理地址
- `VITE_AGNES_MODEL`：自定义模型名，默认 `agnes-3.0-flash`（`agnes-2.0-flash` 已不可用）

> 安全提示：请不要把 API Key 写进前端代码或提交到仓库。前端代码是公开可读的，哈希也不能保护密钥——浏览器必须发送真实 Key 才能调用接口，任何人都可从网络请求中拿到它。
>
> 如果共享代理被限流，可点击 AI 解释弹窗右上角的钥匙图标，填入自己的 API Key。该 Key 只保存在当前浏览器的 localStorage，不会进入代码或上传；应用会直连上游接口。请仅在可信设备上使用，并随时点击「清除」删除本地密钥。

### 出现 `429 - error code: 1015` 怎么办

这是上游服务的 Cloudflare 限流，不是前端代码错误：

1. 等待响应头 `Retry-After` 指定的时间后再试（通常是几分钟）。
2. 为 Worker 绑定 KV 缓存，避免重复问题反复打到上游。
3. 如果持续出现，说明共享 API Key / 出口 IP 被上游限流，需要更换上游服务或提高配额。
4. 应用本身会自动降级到内置资料库，弹窗仍可正常显示解释内容。
